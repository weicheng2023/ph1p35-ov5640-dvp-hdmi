# 工具与自动化

存放环境检查、构建、烧写辅助与报告收集脚本。
**当前尚未实现任何脚本**——TD 工程与下载器信息确认后再编写并实测。

## 1. 计划中的工具

| 脚本 | 用途 | 依赖 |
|---|---|---|
| `check_env.ps1` | 检查 TD、Git、路径与工程入口 | TD 6.2.1 |
| `build.ps1` | 调用 TD 构建，输出到 `build/` | TD 批处理命令（待确认） |
| `program.ps1` | 烧写辅助 | 下载器型号（待确认） |
| `collect_reports.ps1` | 汇总资源/时序报告 | 构建产物 |

## 2. 编写规则

- 兼容 **Windows PowerShell 5.1**；不使用交互式命令。
- 不写死本机绝对路径；路径从仓库根推导或作为参数传入。
- 破坏性操作必须显式开关，默认 dry-run / 只读。
- 输出目录统一为根目录 `build/`，脚本与说明入库。
- TD 命令与参数必须来自实测或官方文档，不凭猜测填写。
- 脚本不得修改 RTL、约束或 IP 参数。

## 3. 目录边界

- 与 FPGA 工程强相关的脚本也可放在 `fpga/scripts/`；
  通用环境/烧写辅助放本目录。两者不重复实现同一功能。
- 静态检查的**结论**放 `verification/static/`，脚本本身放这里。
