# 历史归档

本目录用于保存**不再使用但需要可追溯**的工程、实验与方案。
它是归档区，**不是垃圾桶**。

## 1. 入库条件

必须同时满足：

1. 已被新方案替代，或实验失败但结论有参考价值；
2. 有明确来源、日期、原因和替代位置；
3. 不是仍在维护内容的唯一副本。

## 2. 禁止

- 把用途不明的文件直接丢入；
- 重复保存仍在维护的工程；
- 删除唯一副本；
- 用日期目录批量堆放，替代 Git 历史。

## 3. 归档方式

```text
archive/
└── <topic>_<YYYYMMDD>/
    ├── README.md      来源、归档原因、替代位置、恢复方法
    └── ...            原始内容（保持原结构）
```

`README.md` 必须说明：

- 原路径
- 归档日期与原因
- 被谁替代 / 关联的当前方案
- 是否可恢复、如何恢复
- 是否仍参与构建（应为“否”）
