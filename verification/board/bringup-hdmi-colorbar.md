# HDMI 彩条上板步骤（2026-11-07）

> 目标：不接摄像头、不用 DDR，让 PH1P35 独立输出 640×480 59.98 Hz 的
> 8 色竖条到 HDMI 显示器。
>
> **本文是操作步骤，不是验证结果。** 实测后把结果写入
> `verification/board/evidence/20261107_hdmi_colorbar/README.md`，
> 不要提前标 PASS。

## 0. 准备

- 板卡：PH1P35_FT V1 / HX1P35B_FT_40P，FPGA PH1P35MDG324。
- 显示器：支持 640×480 59.98 Hz 的 HDMI 显示器（大多数都支持）。
- HDMI 线：一根已知良好的线。
- 万用表；有示波器更好（高阻探头/差分探头）。
- 位流：`build/bitstream/top_hdmi_colorbar.bit`
  （SHA-256 `60fb0d0de3aabe36285e1d3cb6ea82bff5e88e271ae18f6374081931c908ef63`）。
- 摄像头**不要接**；本设计不使用 J2 摄像头信号。

## 1. 断电检查（不上电）

1. 断开板卡电源。
2. 用万用表通断档确认 HDMI 连接器 GND（pin 20–23、外壳）与板卡 GND 导通。
3. 确认没有把 5V 接到 FPGA IO 或 3.3V 网络（只做目视/通断，不飞线）。

## 2. 上电、不接显示器时的静态测量

上电，但**先不接 HDMI 线**。用万用表直流档测：

| 测点 | 预期 | 说明 |
|---|---|---|
| HDMI pin 18 对 GND | ≈ 5 V | VCC_5V 经 D5 常供 |
| `+3.3V_HDMI`（R180 上端 / C293/C294） | ≈ 3.3 V | Q17 由 VCC_5V 使能 |
| HDMI pin 19（HPD）对 GND | 低（≈0 V） | 未接显示器；若为高，先整机断电再上电 |
| FPGA B17（HPD 分压） | 低（≈0 V） | 未接显示器 |

如果 `+3.3V_HDMI` 明显低于 3.3 V（例如 <3.0 V），先不要继续；
记录电压，检查 Q17/R200/R201/C297 和 VCC_5V。这会影响 TMDS 偏置。

## 3. 接显示器后的测量

1. 把 HDMI 线接到显示器，显示器上电，输入源选 HDMI1。
2. 再测：

| 测点 | 预期 | 说明 |
|---|---|---|
| HDMI pin 19（HPD） | 高（≈5 V） | 显示器检测到 +5V 后拉高 |
| FPGA B17 | ≈2.5 V | 20K/20K 分压 |
| `HDMI_A0_5V`（U46 OUT / C293） | ≈5 V | U46 由 HPD 使能 |
| `+3.3V_HDMI` | 仍 ≈3.3 V | 带 8 个 49.9 Ω 后确认没有被拉低 |

**HPD 锁存提醒**：D6 会把 `HDMI_A0_5V` 回灌到 HPD 线。首次接入后，
即使拔掉显示器，HPD 也可能保持高，U46 保持使能。要重新做“未插入”
测量时，必须**整机断电重上电**，不要只拔 HDMI 线。

## 4. 下载位流

1. 打开 BitWizard（`TD/bin/bw.exe`）。
2. Refresh → Add bit file → 选择
   `build/bitstream/top_hdmi_colorbar.bit`。
3. **Program SRAM**（首次不要写 Flash）→ Run。
4. 记录下载是否成功、有无报错。

## 5. 预期 LED

| 物理 LED | 含义 | 预期 |
|---|---|---|
| LED1 | 50 MHz 心跳 | 1 Hz 闪烁 |
| LED2 | PLL lock | **常亮** |
| LED3 | 出复位 | **常亮** |
| LED4 | 帧翻转（约 0.94 Hz） | 缓慢闪烁 |

- LED1 不闪 → 50 MHz 时钟/配置问题（与 HDMI 无关）。
- LED2 不亮 → PLL 没锁；先查 `+3.3V_HDMI`、Q17、PLL 配置。
- LED3 不亮 → 复位没有释放（通常与 LED2 同时异常）。
- LED4 不闪但 LED2/3 亮 → 视频计数器/时钟可能没跑。

## 6. 预期显示

- 显示器识别到 640×480 59.98 Hz（或 640×480 59.9/60 Hz）。
- 屏幕出现 **8 条等宽竖条**，从左到右：
  白、黄、青、绿、品红、红、蓝、黑。
- 图像稳定，不滚动、不闪烁、无花屏。

记录：

- 显示器型号、输入源、显示器信息页显示的分辨率/刷新率。
- 屏幕照片（能看清 8 条颜色）。
- LED 状态照片/描述。
- 位流 SHA、下载时间。

## 7. 黑屏/异常时的排查顺序

不要跳级；每步记录实测值。

### 7.1 LED2 不亮（PLL 没锁）

1. 测 `+3.3V_HDMI` 是否 ≈3.3 V；Q17 栅极是否 ≈5 V。
2. 确认位流是 `top_hdmi_colorbar.bit`，不是旧的 DVP 位流。
3. 若供电正常但不锁：记录现象，反馈给开发者；可能需要调整
   `LPF_CAP/ICP_CUR` 或改用 C0 反馈配置重新构建。
4. 不要用“换一块板”掩盖问题；先把电压和位流确认清楚。

### 7.2 LED2 亮，但显示器“无信号”

1. 用示波器高阻探头看 **C17（TMDS CLK P）**：
   - 应有 25.0 MHz 的 TMDS 时钟波形（差分，单端看约 2.8–3.3 V 共模，
     摆幅几百 mV）。
   - 若没有波形：查 C17 约束、TMDS33 配置、`PHY-5016` warning。
2. 看 G16/F17/H14 是否有数据波形（会随彩条变化）。
3. 测 49.9 Ω 上拉后的共模电压；若接近 0 V 或 5 V，检查 `+3.3V_HDMI`
   和 N 端配对。
4. 换一根 HDMI 线、换显示器输入源；确认显示器接受 640×480 59.98 Hz。
5. 本设计**不读 EDID**；少数显示器在无 EDID 时不显示。若怀疑此点，
   记录显示器型号，后续再加 DDC/EDID。

### 7.3 有图像但颜色/条数不对

1. 确认通道映射：D0=Blue、D1=Green、D2=Red。
2. 确认 G16=D0、F17=D1、H14=D2、C17=CLK，没有跨对。
3. 确认位序：编码器 `dout[0]` 先发，串行器 `din[0]` 先发。
4. 若红蓝互换 → D0/D2 通道接反；若整体偏色 → 编码/位序问题。

### 7.4 图像滚动/不稳定

1. 确认像素时钟 25.0 MHz、H/V 总数 800×521。
2. 检查 PLL 是否稳定 lock（LED2 是否闪断）。
3. 可能是像素/串行时钟相位；记录现象，后续调整 `CPHASE` 或
   串行器 load 相位。
4. 不要用普通逻辑分析仪直接接 TMDS；252 Mbps 超出其能力。

## 8. 测量注意事项

- **不要**用 50 Ω 端接探头直接接 TMDS 线到地；会改变电流型驱动负载。
  用高阻探头或差分探头。
- **不要**用普通逻辑分析仪解码 TMDS 数据；只能看低速控制信号
  （LED、HPD、DDC）。
- 测 HPD/DDC 时注意它们是 5V 域；FPGA 侧是 3.3V 域，经过分压/电平转换。
- 每次重新插拔显示器后，若要测“未插入”状态，先整机断电重上电
  （HPD 锁存）。
