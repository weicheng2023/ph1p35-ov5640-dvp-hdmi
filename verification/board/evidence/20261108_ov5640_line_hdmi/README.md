## 5. 解释（不夸大）

当前画面**不是**预期的 8 色条，因此至少有一项未确认：

1. OV5640 内部彩条是否真正生效（`0x503D=0x80` 写入/回读成功，
   但内部彩条输出仍可能是真实场景/其他测试图）；
2. HREF 有效窗口是前半段还是后半段（A/B）；
3. RGB565 高低字节顺序；
4. 行缓存读地址/像素对齐（当前 TB 只证明了色条中心，未证明 ±1 像素边界）。

“左侧黑条 + 右侧浅蓝紫”更像是**真实场景/测试图被截取了一部分**，
而不是标准 8 色条；但在没有新的板上证据前，不能把它判定为某一种确定原因。
