# 接线电气检查表（ATK-MC5640 → PH1P35 J2）

> **用途**：在第一次给摄像头通电、第一次下载 FPGA 位流之前，按步骤用万用表
> 核对接线，避免把电源接反、把信号接地或把 5 V 引入 3.3 V 器件。
>
> **状态**：本表尚未执行。所有“实测”栏必须由操作者填写真实读数；
> 本文不预填任何测量结果。
>
> **前置修正**：`docs/hardware/wiring.md` 已修正原表的 GND/SCL 错位：
> **GND 接 J2-32，SCL 接 J2-30（GPIOB_27）**。若实物仍按旧表接线，先换线再检查。

## 0. 安全规则

1. **所有通断/电阻检查必须在完全断电、USB 拔掉、摄像头排线拔掉的状态下进行。**
2. 不要用万用表的电流档去测电压；测电压用 DC V 档，测通断用蜂鸣/电阻档。
3. 不要同时连接 J2-11（5 V）和摄像头 3.3 V。
4. 第一次上电建议使用带限流的电源，限流先设在 100 mA 左右。
5. 发现发热、异味、电流异常立即断电。
6. 若读数与本文“正常结果”不符，停止并记录，不要“先上电试试”。

工具：

- 数字万用表（通断/蜂鸣、DC V、电阻）
- 杜邦线/排线若干（用于确认）
- 绝缘镊子或探针（避免相邻针短路）
- 开发板与摄像头的原理图打印件或本文

## 1. 断电外观检查

### 1.1 确认两个连接器的 Pin 1 方向

- **为什么**：IDC40 和 2×9 排针都有方向；反插会把电源接到信号脚。
- **怎么做**：
  1. 找到开发板 J2 的 Pin 1 标记（连接器缺口、丝印“1”或方形焊盘）。
  2. 找到摄像头 P1 的 Pin 1 标记（模组丝印/连接器缺口）。
  3. 对照 `docs/hardware/wiring.md` 第 2 节，确认排线两端的方向。
- **正常结果**：两端 Pin 1 与接线表一致，排线不反插。
- **异常处理**：不要上电；重新压线或换排线，记录实际方向。
- **实测记录**：J2 Pin 1 位置：__________；P1 Pin 1 位置：__________。

### 1.2 检查接线是否松动、相邻针是否短接

- **为什么**：杜邦线松动会造成间歇故障；相邻针短接可能把 3.3 V 接到信号。
- **怎么做**：逐根轻拉，确认端子锁紧；目视相邻针之间无金属丝/焊锡搭接。
- **正常结果**：每根线受力不脱落，相邻针无可见短接。
- **异常处理**：重新压端子/换线；清理短路处。
- **实测记录**：__________。

## 2. 断电通断检查

> 以下检查均在**开发板断电、摄像头排线拔掉**的状态下，用蜂鸣档/电阻档进行。
> 先把两端排线从板上拔下，直接量排线两端，可避免板内网络干扰。

### 2.1 逐根核对 ATK P1 → J2

按 `docs/hardware/wiring.md` 第 2 节逐根测量。重点核对：

| ATK P1 | 信号 | 应到 J2 | 实测 J2 | 通断（是/否） |
|---:|---|---:|---:|---|
| 1 | GND | **32** | | |
| 2 | 3.3V | 29 | | |
| 3 | SCL | **30** | | |
| 4 | VSYNC | 21 | | |
| 5 | SDA | 33 | | |
| 6 | HREF | 20 | | |
| 7 | D0 | 22 | | |
| 8 | RESET | 34 | | |
| 9 | D2 | 24 | | |
| 10 | D1 | 23 | | |
| 11 | D4 | 26 | | |
| 12 | D3 | 25 | | |
| 13 | D6 | 28 | | |
| 14 | D5 | 27 | | |
| 15 | PCLK | **7** | | |
| 16 | D7 | 31 | | |
| 17 | PWDN | 35 | | |
| 18 | NC | 不接 | — | — |

- **为什么**：这是唯一能发现“图纸正确但实物插错”的步骤。
- **怎么做**：一端探针接 ATK P1 的指定脚，另一端接 J2 的指定脚；听蜂鸣/看阻值。
- **正常结果**：对应脚导通（一般 < 数 Ω，含排线电阻）；**非对应脚不导通**。
- **异常处理**：若 GND 通到 J2-30 或 SCL 通到 J2-32，说明仍在用旧表，必须换线。
- **特别注意**：J2-30 是 GPIOB_27，**不是地**；J2-32 才是地。

### 2.2 检查 3.3 V 与 GND 是否短路

- **为什么**：3.3 V 对地短路会烧毁板卡稳压器或摄像头。
- **怎么做**：断电，万用表电阻档，测 J2-29 与 J2-32 之间；再测摄像头 P1-2 与 P1-1。
- **正常结果**：电阻为数十 kΩ 以上（可能有滤波电容，读数会先低后升）。
- **异常处理**：若接近 0 Ω，禁止上电，排查短路。
- **实测记录**：J2-29↔J2-32：______；P1-2↔P1-1：______。

### 2.3 检查 5 V 是否误接

- **为什么**：J2-11 是 5 V，接摄像头 3.3 V 会过压。
- **怎么做**：断电，确认摄像头 3.3 V 线只到 J2-29，**没有任何线到 J2-11**；
  用通断档确认 P1-2 与 J2-11 不导通。
- **正常结果**：P1-2 与 J2-11 不导通。
- **异常处理**：立即改线。
- **实测记录**：__________。

### 2.4 检查 PCLK 是否在 J2-7

- **为什么**：PCLK 曾从旧的 D4 方案改到 F14；必须确认实物也已改。
- **怎么做**：通断档测 ATK P1-15 到 J2-7；同时确认 P1-15 不再接到旧的 J2-34/D4 方案。
- **正常结果**：P1-15 ↔ J2-7 导通；与 J2-34 不导通。
- **异常处理**：改线；不要保留旧 PCLK 分配。
- **实测记录**：P1-15↔J2-7：______；P1-15↔J2-34：______。

### 2.5 检查相邻信号是否短接

- **为什么**：排线压接不良可能让相邻数据位短接，图像会出现固定花屏。
- **怎么做**：在排线两端，逐对测量相邻信号（D0/D1、D1/D2…、SCL/SDA、PCLK/GND）。
- **正常结果**：相邻信号之间不导通。
- **异常处理**：重新压线/换排线。
- **实测记录**：__________。

## 3. 独立供电检查（摄像头暂不连接）

> 目的：先确认开发板 J2 的电源脚正确，再插摄像头。
> 此时**摄像头排线必须拔掉**。

### 3.1 测量 J2-29 的 3.3 V

- **为什么**：确认摄像头供电脚确实是 3.3 V，而不是 5 V 或悬空。
- **怎么做**：
  1. 开发板上电（仅 USB/DC，摄像头不接）。
  2. 万用表 DC V 档，黑表笔接 J2-32（GND），红表笔接 J2-29。
- **正常结果**：3.2–3.4 V。
- **异常处理**：若为 5 V、0 V 或跳动，断电检查板卡供电与 J2 引脚定义。
- **实测记录**：______ V。

### 3.2 确认 J2-32 为 GND

- **为什么**：GND 接错会让摄像头无回流地。
- **怎么做**：断电，通断档测 J2-32 与板卡 GND 测试点/USB 外壳；上电后测 J2-32 对 GND 电压。
- **正常结果**：断电导通；上电后 0 V。
- **异常处理**：若 J2-32 不是 0 V，停止。
- **实测记录**：______ V / 通断：______。

### 3.3 确认 J2-11 是 5 V 且不接摄像头

- **为什么**：J2-11 是 5 V，不能作为摄像头 3.3 V。
- **怎么做**：上电，黑表笔 J2-32，红表笔 J2-11。
- **正常结果**：约 5 V；摄像头 3.3 V 线未接此脚。
- **异常处理**：若摄像头已接 J2-11，立即断电改线。
- **实测记录**：______ V。

### 3.4 确认 J2-30 不是电源

- **为什么**：J2-30 是 GPIOB_27，不是 GND；旧表容易误判。
- **怎么做**：上电，测 J2-30 对 J2-32 的电压；再用通断档确认 J2-30 与 J2-29/32 不导通。
- **正常结果**：J2-30 对地不是稳定 0 V/3.3 V 电源（可能浮空或由 FPGA 决定），
  且与电源脚不导通。
- **异常处理**：若 J2-30 被当作 GND 使用，改到 J2-32。
- **实测记录**：______ V。

## 4. 摄像头连接后的上电检查

> 仅在 2、3 节全部通过后进行。建议使用限流电源，限流 100 mA。

### 4.1 检查摄像头 3.3 V 与电流

- **为什么**：确认模组供电正常、无过流。
- **怎么做**：接好排线，上电；测模组 P1-2 对 P1-1 电压；观察电源电流。
- **正常结果**：3.2–3.4 V；电流约数十 mA（模组标称约 56 mA，AF/LED 动作时会升高）。
- **异常处理**：电流接近限流、电压跌落、发热 → 立即断电。
- **实测记录**：电压 ______ V；电流 ______ mA。

### 4.2 检查模组温升

- **为什么**：LDO 或传感器异常会发热。
- **怎么做**：上电 1 分钟后触摸模组（注意防静电），或用手持测温。
- **正常结果**：温热，不烫手。
- **异常处理**：明显发烫 → 断电排查。
- **实测记录**：__________。

## 5. FPGA 配置前的 IO 检查

### 5.1 确认 Bank 电压与 IOSTANDARD

- **为什么**：BANK32/BANK22 的 VCCIO 必须是 3.3 V，约束才能用 LVCMOS33。
- **怎么做**：查原理图/测板卡 VCCIO 测试点；确认 J2 使用的 GPIO 属于这两个 Bank。
- **正常结果**：VCCIO_32、VCCIO_22 均为 3.3 V。
- **异常处理**：改约束或改板卡配置，不能强行用 LVCMOS33。
- **实测记录**：__________。

### 5.2 确认 SCCB 上拉

- **为什么**：SCL/SDA 是开漏总线，没有上拉就无法通信。
- **怎么做**：断电，测 SCL/SDA 对 3.3 V 的电阻；确认板上/模组是否有 4.7 kΩ 上拉。
  当前两份原理图都未画出上拉，**默认按“没有上拉”处理**。
- **正常结果**：有明确上拉（约 4.7 kΩ）或已确认 FPGA 内部上拉足够。
- **异常处理**：补 4.7 kΩ 上拉到 3.3 V（或按模组 IO 电压），再上电。
- **实测记录**：SCL 对 3.3 V：______；SDA 对 3.3 V：______。

### 5.3 确认 RESET / PWDN 默认电平

- **为什么**：FPGA 未配置完成时，这两根线浮空可能让摄像头处于复位/掉电状态。
- **怎么做**：上电但**不下载 FPGA 位流**，测 P1-8（RESET）和 P1-17（PWDN）对 GND 电压。
- **正常结果**：RESET 为高（不复位）、PWDN 为低（不掉电）；或至少状态确定、不浮空。
- **异常处理**：若浮空/错误，增加 10 kΩ 上拉/下拉或确保 FPGA 配置后立即驱动。
- **实测记录**：RESET ______ V；PWDN ______ V。

### 5.4 确认 FPGA 未配置时不会输出冲突

- **为什么**：摄像头输出 DVP 信号时，若 FPGA 引脚被配置为输出，可能对驱动。
- **怎么做**：确认 RTL 中 DVP 数据、PCLK、VSYNC、HREF 均声明为输入；
  FPGA 配置前为高阻/弱上拉，不与摄像头输出对驱。
- **正常结果**：所有 DVP 信号方向为 input；SCCB/RESET/PWDN 为 output。
- **异常处理**：修改 RTL 方向；不要在未确认时下载位流。
- **实测记录**：RTL 审查结果：__________。

## 7. 本表不能证明什么

- 不能证明摄像头内部传感器完好。
- 不能证明 SCCB 寄存器配置正确。
- 不能证明 DVP 时序/采样边沿正确。
- 不能证明 HDMI 输出正常。
- 不能替代示波器/逻辑分析仪对 PCLK、VSYNC、HREF 的波形检查。

这些属于后续 RTL 与上板验证阶段，必须在 `verification/board/` 留下新的证据。
