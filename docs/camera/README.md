### 2.1 极性：VSYNC 已实测；HREF 仍有 A/B 两种解释（2026-10-26/28）

同一块模组、同一 LA 接法下：

- `0x4740 = 0x23`：VSYNC **空闲高、66.665 µs 低脉冲** → **低有效**。
- `0x4740 = 0x22`：VSYNC **空闲低、66.665 µs 高脉冲** → **高有效**。
- PCLK 两次都是 **48.000 MHz**（不是 50 MHz，见 §2.2）。

结论：**`0x4740` bit0 在本模块/板上的实际效果与 datasheet 描述相反**
（或模组/FPGA 侧有反相）。正点原子/ST 驱动的低有效 VSYNC 定义对应 `0x23`
的实测波形。

必须选一对**一致**的组合：

| 配置 | FPGA 参数 | 结果 |
|---|---|---|
| `0x23` | `VSYNC_ACTIVE_HIGH=0` | 低有效，帧边界取低脉冲开始沿 |
| `0x22` | `VSYNC_ACTIVE_HIGH=1` | 高有效，帧边界取高脉冲开始沿 |

16:24 诊断位流使用 `0x22` + `VSYNC_ACTIVE_HIGH=1`，这一对是自洽的。

**HREF 极性尚未最终证明。** 实测 HREF 高约 40 µs（1920 PCLK）、低约
26.665 µs（1280 PCLK），有两种自洽解释：

- **A. 低有效**：低相位 1280 PCLK 就是 640 像素 RGB565 的有效数据；
  高相位 1920 PCLK 是消隐。
- **B. 高有效**（datasheet `0x22` bit1=1）：高相位前 1280 字节是有效数据、
  后 640 字节是 dummy/padding；低相位 1280 PCLK 是消隐。此时
  `HREF_ACTIVE_HIGH=0` + `EXPECTED_PIX=1280` 会抓到消隐，长度也正好
  1280，**LED4 仍会熄灭，但是假成功**。

16:24 位流的 LED4 熄灭只证明行长度/行数计数对齐，**不证明像素数据正确**。
必须用 D0–D7 彩条比较低/高两相，才能定 HREF 极性（见
`verification/board/evidence/20261028_dvp_11ch/README.md` §3.4）。

其他要点：

- 回读 `0x4740` 只能确认寄存器值，**不能确认引脚极性**；极性必须 LA 实测。
- HREF 在垂直消隐期间有一次 **1.373 ms** 的长高，VSYNC 脉冲落在这段
  高电平内；行计数仍是 **480**，不要把它当成第 500 行。
- `VSYNC_ACTIVE_HIGH` 必须与 `0x4740` 配对；`HREF_ACTIVE_HIGH` 等
  D0–D7 两相对比后再定，不要用 LED4 单独定。

### 2.2 时钟/帧率：已实测（2026-10-26，2026-10-28 修正）

- 实测 PCLK = **48.000 MHz**，周期 **20.833 ns**。ALIENTEK 注释的
  “48 MHz”是对的；旧文档的 50 MHz 是 20 ns 粗量化误读。
  - 0.5 s 内 24,000,131 个上升沿 = 48.000 MHz；
  - 13:41/13:58 两次 11 通道捕获的平均周期都是 20.833 ns。
- VSYNC = **30 Hz**，周期 **33.333 ms**，脉宽 **66.665 µs**（恰好一行）。
- HREF = **15 kHz**，周期 **66.665 µs = 3200 PCLK**；高 **40 µs = 1920 PCLK**，
  低 **26.665 µs = 1280 PCLK**。
- 每帧 **480 个 HREF 上升沿**（不是 500）；33.33 ms / 66.665 µs = 500 个
  行周期，其中约 20 行是垂直消隐，HREF 表现为一次 **1.373 ms 的长高**。
- 配置的 RGB565 有源宽度是 640 像素 = 1280 字节；低相位正好 1280 PCLK，
  高相位 1920 PCLK。**这 1280 字节在低相位还是高相位前段，尚未用 D0–D7
  证明**（A/B 两种解释见 §2.1）。
- 16:24 诊断位流使用 `EXPECTED_PIX=1280`、`EXPECTED_LINES=480`；
  `EXPECTED_LINES=480` 已被 LA 证实，不要改成 500。
- SDC 的 50 MHz 对 48 MHz 偏保守，暂不影响功能；不要为了“看起来一致”
  在信号问题未查清前重建。
- 2026-10-28 的 11 通道尝试失败：HREF 单测出现 29.53 kHz，更像摄像头
  复位后回到默认 1280×960 时序；详见
  `verification/board/evidence/20261028_dvp_11ch/README.md`。

## 3. 配置表使用原则

- 以 ALIENTEK V1.0 的 RGB565 表为**初始化参考**，逐条核对来源和副作用。
- 本项目自己的 `ov5640_cfg.v` 使用自己的表格式和状态机；不复制参考工程的
  Verilog 结构或注释。
- 与参考表的有意差异必须记录：
  - 增加 `0x4740 = 0x22`（实测 VSYNC 高有效；HREF 引脚极性待确认）；
  - 彩条测试用 `0x503D = 0x80`，正常模式 `0x00`；
  - 分辨率/总行场参数作为模块参数，默认值在实测后确定；
  - 参考表开头的 `0x300A/0x300B = 0` 哑写不纳入，除非确认其作用。
- 配置完成后读回关键寄存器：`0x300A/0x300B`、`0x4300`、`0x4740`、
  `0x3808~0x380B`、`0x503D`、`0x3035~0x3037`、`0x3108`。
  读回不匹配时置错误标志，不要静默继续。
