> **状态（2026-10-23）**：接线表已按原理图核对并修正；用户报告实物已接线，
> 但**万用表检查、上电检查和 FPGA 功能测试均未完成**。

> **请勿上电**，先按本文第 2 节换线并完成万用表检查。

## 4. 信号方向与作用

- **SCL / SDA**：FPGA 作为 SCCB 主机配置 OV5640 寄存器。SCL 由 FPGA 输出；
  SDA 双向，需要上拉。SCCB 不是标准 I²C，但时序与 I²C 兼容。
- **RESET**：FPGA 控制摄像头复位，低有效。上电初始化时应先释放复位，再配置寄存器。
- **PWDN**：FPGA 控制摄像头掉电，高有效。正常工作时必须为低。
- **PCLK**：摄像头输出的像素时钟，FPGA 用它采样 DVP 数据。
- **VSYNC / HREF**：场/行同步。具体在 PCLK 的哪个边沿采样、HREF 的有效极性，
  必须在 RTL 阶段以 OV5640 手册和实测波形确认；本文不预设采样边沿。
- **D0–D7**：8-bit 并行像素数据，摄像头 → FPGA。
- **3.3V / GND**：模组供电与回流地。

## 5. 电气注意事项

### 5.1 供电

- 摄像头 3.3 V 只能接 **J2-29**；回地接 **J2-32**。
- **J2-11 是 VCC_5V，禁止连接摄像头 3.3V 或任何摄像头信号。**
- 模组标称功耗约 56 mA；上电时建议使用限流电源或可恢复保险丝，先观察电流。
- 摄像头模组板载 LDO（3.3 V → 2.8 V / 1.5 V），P1 只输入 3.3 V。

### 5.2 GPIO Bank 电压

- 使用的 GPIOB_6/17–30 分布在 **BANK32** 和 **BANK22**。
- 原理图显示 `VCCIO_32`、`VCCIO_22` 均接 `VCC_3V3`，因此约束使用 **LVCMOS33**。
- 迁移到其他板卡或改 Bank 电压时，必须重新确认 IOSTANDARD，不能照抄。

### 5.3 2.8 V IO 与 3.3 V FPGA 的兼容性

- 正点原子 README 明确：模组 IO 电平 **2.8 V，兼容 3.3 V**。
- FPGA 输出 3.3 V 到模组输入，依赖该兼容性声明；原理图上没有电平转换器。
- 板卡在连接器与 FPGA 之间有 47 Ω 串联电阻，可限制边沿电流，但不等于电平转换。
- 模组输入高电平门限、FPGA 输入高电平门限均应以各自手册复核；
  当前结论是“按厂商声明可用”，**不是实测结论**。

### 5.4 SCCB 上拉

- **板卡 `P05_GPIO` 原理图未发现 SCL/SDA 上拉电阻**，只有 47 Ω 串联电阻和 RClamp。
- **摄像头 `ATK-MC5640 V1.2` 原理图也未发现 SCL/SDA 上拉电阻**。
- SCCB 是开漏/开集总线，必须有上拉。当前方案缺少明确的外部上拉，
  属于**上电前必须确认的电气风险**。
- 建议：在 SCL、SDA 上各加 4.7 kΩ 上拉到 3.3 V（或按模组 IO 供电选择 2.8 V），
  或在确认 FPGA 内部弱上拉参数与总线速率后再决定是否可用。
  在补装/确认之前，不要假定 SCCB 一定能通信。
- 若使用 FPGA 内部上拉，必须查阅 PH1P35 手册确认阻值与是否足够驱动总线电容；
  不能仅凭“能编译”判断。

### 5.5 RESET / PWDN 默认电平

- 两颗信号在板卡和摄像头原理图上都**没有外部上/下拉电阻**。
- FPGA 未配置完成前，用户 IO 可能处于高阻或弱上拉状态；板上 `HSWAPEN`
  通过 R285 1 kΩ 下拉，配置期间的具体上拉行为需按 PH1P35 手册确认。
- 因此上电瞬间 RESET/PWDN 可能浮空：PWDN 浮高会让摄像头保持掉电，
  RESET 浮低会让摄像头一直复位。
- 建议在硬件上增加安全默认：PWDN 10 kΩ 下拉、RESET 10 kΩ 上拉（到 3.3 V），
  或确保 FPGA 配置后第一时间驱动这两根线。当前**未实施**，仅作为检查项。

### 5.6 PCLK 时钟引脚

- PCLK 接 **F14**，原理图标注 `IO_R14P_32,GCLKIOT3,T1`，属于 BANK32 的
  全局时钟能力 IO。
- 是否可以直接作为全局时钟输入、是否需要 TD 的时钟缓冲/专用路由，
  必须在 TD 综合与布局布线时确认；本文只做引脚分配，不预设时钟资源。
- **暂不添加 PCLK 时序约束**：PCLK 频率取决于 OV5640 寄存器配置，
  当前尚未确定。等频率确定并实测后再写 `create_clock`，不得为了“时序通过”
  添加 false path。

### 5.7 DVP 连线与地回流

- DVP 是单端并行总线，PCLK 与 8 根数据线应尽量短、成束、远离高噪声电源线。
- 至少保证 P1-1 GND 与 J2-32 可靠连接；不要依赖 USB/HDMI 屏蔽层回流。
- 若使用杜邦线，优先缩短长度并固定，避免 PCLK 边沿振铃和相邻数据线串扰。

### 6.1 摄像头 P1 原理图符号编号说明

- 官方 README 的物理排针表为：1 GND、2 3V3、3 SCL、4 VSYNC、5 SDA、6 HREF、
  7 D0、8 RESET、9 D2、10 D1、11 D4、12 D3、13 D6、14 D5、15 PCLK、16 D7、
  17 PWDN、18 NC。
- V1.2 原理图的 `Header 9X2` 符号把 SCL 画在符号引脚 1、VSYNC 在 2，
  与物理排针号相差 2 位；原理图符号的引脚号**不能直接当作物理 P1 引脚号**。
- 本文采用官方 README 的物理排针表；信号顺序已与原理图逐行对应确认。
- 官方模组照片显示 **GND / 3.3V 位于 2×9 排针的同一端**，与 README 表一致；
  信号丝印（SCL/SDA/D0/D2/D4/D6/PCLK/PWDN 与 VSYNC/HREF/RST/D1/D3/D5/D7/NC）
  也与本表一致。
- **仍需人工确认**：实物 Pin 1 的具体方向（以模组丝印/连接器缺口为准），
  以及 1/2 脚确实为 GND/3V3。上电前用万用表核对，不能只看照片或图纸。
